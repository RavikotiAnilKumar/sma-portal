# SMA Awareness and Community Knowledge Assessment Portal

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/RavikotiAnilKumar/sma-portal)

This is a unified Web and Backend application for the SMA Awareness Community Service Project.

## 🚀 Deployment Status
Your project is configured for **Automatic Cloud Deployment**. 

### How to host:
1. Click the **Deploy to Render** button above.
2. Approve the Blueprint on Render.
3. Your site will be live at `https://sma-portal-backend.onrender.com/index.html`

## 📁 Project Features
- **Education:** 11+ pages of SMA content.
- **Survey:** Smart multi-step questionnaire with instant scoring.
- **Analytics:** Dynamic charts using Chart.js.
- **Security:** Admin registration and login system.
- **Mapping:** Live activity map with geo-tagging.
